# Folder Lock 文件夹加密

[English README](README.md)

为文件夹或单篇笔记设置独立密码，并支持嵌套多层加密。

- 右键文件夹或 Markdown 笔记即可添加保护。
- 每个保护项使用各自的密码；已锁定文件夹中的文件还可以再设一层密码。
- 锁定的文件夹在解锁前不能展开。
- 点击被锁定的文件夹或笔记会立即弹出密码框；密码错误或取消则回到原来的界面。
- 源码模式、预览、悬浮预览和嵌入中都不会显示密文或密钥材料。
- 可选空闲自动锁定。界面默认中文，可切换为 English。

## 安装

插件进入社区目录后，可在 **设置 → 第三方插件** 中安装。

从 GitHub Release 手动安装：

1. 在 [最新 Release](https://github.com/davidwanghaoming/obsidian-folder-lock/releases) 下载 `main.js`、`manifest.json` 和 `styles.css`。
2. 放到库的 `.obsidian/plugins/folder-lock/` 目录。
3. 升级时请保留原有 `data.json`，不要重置或覆盖。
4. 重启 Obsidian 并启用 **Folder Lock**。

从源码构建：执行 `npm ci && npm test && npm run build`，再将 `dist/main.js`、`dist/manifest.json`、`dist/styles.css` 复制到上述插件目录。

**从 0.1 / v1 密文升级：** 保留原配置，先「解锁全部」，再「锁定全部」。只有这样，已有文件才会升级为可独立恢复的 v2 格式。丢失原 `data.json` 时，旧格式无法恢复。

## 使用

1. 右键文件夹或 `.md` 笔记，选择「保护此文件夹」或「为此文件单独加密」；也可以在设置中填写库内路径，再点「添加保护」。密码至少 8 个字符。
2. 锁定的文件夹会保持收起，受保护项会显示锁图标。**直接点击即可输入密码**；取消或输错会停留在原来的界面。
3. 笔记要解开全部层才会打开正文：先外层，后内层。只点击文件夹则只解开文件夹层，内层文件仍锁定；取消内层提示，不会把已经解开的外层重新锁上。
4. 侧栏锁图标可锁定或解锁全部；设置和右键菜单可以操作单项。更改密码或取消保护都需要当前密码，且须先解开本层及其外层。
5. 设置中的「自动锁定」可在空闲一段时间后锁定；设为 `0` 即关闭。退出、崩溃、休眠或转入后台不保证触发，离开前请手动锁定。

### 配置损坏怎么办

在设置或命令面板中使用「从文件恢复保护配置」。v2 格式会在经过认证的文件头中保存每层的 ID、盐、迭代次数和密码校验值（**这些不是密码或密钥**），从而重建索引。解锁时仍须用原密码通过 AES-GCM 完整性验证。

删除配置后直接打开 v2 密文，也会尝试恢复。若配置与文件头不一致，插件会停止操作，不会用替换后的密码覆盖密文。文件头冲突同样会停止恢复，请检查备份。

恢复仅适用于仍带有 v2 文件头的层；已全部解锁的层没有可恢复的文件头。v1 格式必须保留原 `data.json`。**忘记密码无法恢复。** 请同时备份笔记和 `data.json`。

## 安全边界

- 密码和密钥不落盘。加密使用 Web Crypto AES-GCM-256，随机 12 字节 IV，每个保护项独立 16 字节盐，PBKDF2-SHA-256 迭代 600,000 次。文件头作为 AAD 认证，被改动会导致校验失败。
- 界面只显示名称、类型和锁定状态。源模式、预览、悬浮预览与嵌入会把受保护内容替换为锁定占位符，且不会用占位符覆盖真实文件。磁盘上的加密笔记是隐藏注释块加上简短的锁定提示。
- **这不是操作系统级的访问控制。** 有磁盘权限的人仍可删除或破坏文件，或停用本插件。恶意或不兼容的插件也可能绕过显示钩子。不能保证禁用本插件后仍隐藏密文，更不能保护已解锁的明文。
- 只加密可见的 `.md` 正文；附件、隐藏文件、路径和文件名都不加密。解开全部层后，磁盘上是明文。请先暂停 Git 或同步（包括 Git），或把这些文件夹加入 `.gitignore`。旧的 Git 历史、备份、文件恢复和缓存中仍可能留有明文。
- 锁定时会保存并关闭相关标签页。操作期间请不要编辑，也不要多设备同时写入。插件会先做预检查和回读校验，再逐篇原子写入；磁盘故障仍可能导致部分完成，此时会停止并报告，不会自动冒险回滚。
- 重命名及整体移动受保护文件夹会跟踪路径。携带密文跨保护边界前请先解锁；若误移，请先移回。插件停用期间的移动无法跟踪。
- 文件列表折叠依赖未文档化的内部接口。若这些接口在更新后变化，折叠保护可能失效，插件会退回为打开时再验证密码。若核心显示钩子不兼容，会隐藏笔记视图，而不是直接显示密文。
- 解开外层后如果取消内层密码，外层会保持已解锁状态。

## 开发

```bash
npm ci
npm test
npm run build
```

构建产物在 `dist/`。测试使用 Node 的 Web Crypto、内存库和模拟 DOM。用于重要资料前，请在真实的 Obsidian 库中验收：文件夹折叠与键盘展开、错误密码与取消返回、源码/预览/悬浮/嵌入、多窗口以及嵌套解锁。
